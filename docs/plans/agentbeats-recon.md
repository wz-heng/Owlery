# AgentBeats Phase 0 侦察盒

2026-11-16 · Albus 起草,用户拍板开盒 · 时间盒 1 天 · 预算 $0(只查不跑)

## 背景与动机

第三方榜线 2026-11-16 收线定案:Terminal-Bench 全系列与 HAL 均不接受第三方提交,
当时口径为「2026-11 时点不存在对第三方开放的可挂名 agent 评测通道」。

AgentBeats(Berkeley RDI,arXiv 2606.13608,2026-06)是收线后出现的唯一候选翻案:
评测本身 agent 化——绿 agent 当考官(定任务/环境/判分),紫 agent 当考生,双方走
A2A 协议;考生在 agentbeats.dev 自助注册,提交走 GitHub Actions / fork+PR,
**不需要维护者点头**。其判分哲学(跨 benchmark 通用性+成本效率)贴合 Owlery
「通用工作台」叙事。曾办 AgentX–AgentBeats 竞赛(Phase 2 Sprint 4 于 2026-05 收官)。

本盒只回答一个问题:**AgentBeats 是否构成可用的第三方评测通道**。不跑任何评测。

## 四个核实点(按致命程度排)

1. **平台生死**。AgentX 竞赛 5 月收官,现在 11 月。agentbeats.dev / agentbeats.org
   的榜单是否还活着:是否仍接受竞赛外的常设提交、最近一次提交/榜单更新时间、
   现存 scenario(绿 agent)数量。学生赛办完平台即凉是头号风险,凉 = 全案归档。
2. **场景匹配度**。现存绿 agent 清单(已知:OfficeQA、Minecraft、Build What I Mean、
   CAR-bench、browsecomp-plus 等);有没有贴近终端/开发工作流的场景;如没有,
   最接近 Owlery 本职的是哪个、差多远。注意 GAIA 侦察盒已证:一次性考题上
   Owlery ≈ 裸模型,预期名次是中游,这不改变——要评估的是场景对叙事的价值。
3. **trace 公开范围(闸门 0′)**。绿 agent 把交互日志流成 artifact 公开。核实:
   提交后哪些内容公开、system prompt / 人设是否会暴露、是否有控制手段。
   不可接受且无法规避 → block,与 HAL 同判。
4. **A2A 适配成本**。Owlery 真实栈外包一层 A2A 适配器的工作量级估算(接口面:
   session/delegation API → A2A task)。只估不做。红线沿用 Terminal-Bench 案:
   **必须走 Owlery 真实栈,禁止搭考试专用壳**。

## 预注册判据(冻结,看结果前不改)

- 平台凉(无常设提交通道,或榜单停更无人维护)→ 归档,「无开放通道」定案不动。
- trace 暴露不可避 → block,归档,定案不动。
- 平台活 + 有可用场景 + 暴露可控 → 修订「无开放通道」口径,产出第二闸材料
  (选定场景 + 十题级成本外推),**烧钱前由用户拍板**,本盒不越闸。
